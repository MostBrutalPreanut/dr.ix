# דריקס OS

אפליקציה פנימית לניהול העסק: נהלי פתיחה וסגירה, משימות יומיות, הערות למשמרת, ספר נהלים עם חיפוש, ומנוע המלצות למשחקי קופסה. בהמשך: טיפים, מלאי, הזמנות Wix וקופה.

אפליקציית ווב (PWA) בעברית, מותאמת לטלפון, לטאבלט ולמחשב. אפשר להתקין אותה למסך הבית.

## מה יש עכשיו (שלבים 0-2)

| אזור | תיאור |
|---|---|
| כניסה | בחירת שם + קוד בן 4 ספרות (ברירת מחדל `0000`, ובכניסה הראשונה מציעים לבחור קוד אישי) |
| היום | הערות למשמרת (עם "ראיתי"), צ'קליסטים של פתיחה, סגירה והעברת משמרת, משימות הניקיון של היום (עם הסבר, ומשימה שלא בוצעה מסומנת כבאיחור) |
| נהלים | 15 פרקים מה-PDF עם חיפוש בכל הטקסט, ועריכה למנהלים |
| משחקים | המלצה לפי מספר אורחים, גיל, סגנון ורמה, וכל המשחקים עם הוספה ועריכה למנהלים |
| ניהול (מנהלים) | הערות למשמרת לכל תאריך, עובדים (הוספה, מחיקה, איפוס קוד), עריכת צ'קליסטים, עריכת משימות ניקיון |

תוכנית העבודה המלאה: טיפים (שלב 4), מלאי (5), קופה (6), הזמנות Wix (3). ראו [docs/wix-api-setup.md](docs/wix-api-setup.md).

## הרצה

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # בדיקות לוגיקה (טיפים, משימות חוזרות, המלצות משחקים)
npm run build      # בנייה ל-dist/ (אתר סטטי, אפשר לשים בכל אירוח)
```

ללא הגדרות נוספות האפליקציה עובדת במצב **מקומי**: הנתונים נשמרים בדפדפן של המכשיר.
כדי שכל העובדים יראו את אותו מידע, מחברים Supabase:

1. יוצרים פרויקט ב-[supabase.com](https://supabase.com) (חינם).
2. ב-**SQL Editor** מדביקים ומריצים את [supabase/gateway.sql](supabase/gateway.sql). הוא יוצר את הטבלאות, נועל אותן, ומגדיר כניסה והרשאות בשרת. אפשר להריץ שוב בכל עת בלי לאבד תוכן.
3. יוצרים קובץ `.env.local` (לפיתוח) עם:
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=sb_publishable_...
   ```
4. בונים מחדש (`npm run build`) ומעלים את `dist/`.

הכתובת והמפתח הציבורי של הפרויקט הנוכחי כבר ב-`.env.production`, ולכן בנייה ל-production מתחברת אוטומטית.

### פרסום (בלי טרמינל)

ב-[Netlify](https://www.netlify.com): Add new site ← Import an existing project ← GitHub ← בחירת המאגר `dr.ix` והענף. ההגדרות (`netlify.toml`) כבר בפנים. כל push חדש לענף מפרסם גרסה חדשה.

כל הגישה לנתונים עוברת שער מאובטח עם כניסה והרשאות בשרת. ראו [docs/security.md](docs/security.md).

## מבנה

```
src/lib/        לוגיקה (טיפים, משימות חוזרות, המלצות, תאריכים) + שכבת נתונים (db.ts) + כניסה
src/seed/       תוכן התחלתי: עובדים, צ'קליסטים, משימות, משחקים
src/content/handbook/*.md   פרקי הנהלים (נטענים פעם אחת ואז נערכים מתוך האפליקציה)
src/pages/      מסכים
supabase/       gateway.sql: טבלאות, כניסה והרשאות בשרת
docs/           מדריך Wix, אבטחה, בדיקת תוכן
```

## כללים עסקיים שמוגדרים בקוד

- **יום עסקי:** עד 05:00 בבוקר עדיין נחשב היום הקודם (משמרת שנסגרת ב-01:00).
- **טיפים** (`src/lib/tips.ts`): עובדים רגילים מקבלים חלק שווה. מתגבר מקבל חלק יחסי לשעות שעבד מתוך משמרת מלאה (8 שעות, ובשבת 14). כל הסכום מחולק, בדיוק לאגורה.
- **משימות אחת לשבועיים:** לפי שבוע א׳/ב׳ שניתן להחליף בניהול ← משימות ניקיון.

## מלאי

לשונית "מלאי" לכל העובדים: מדווחים מספיק/מעט/נגמר (או ספירה / צילום) על הפריטים של היום, ורשימת "חסר" נבנית אוטומטית ונשלחת בהעתקה לוואטסאפ. מנהלים ועורכי מלאי עורכים פריטים, קטגוריות, ימי בדיקה וסדר דרך ניהול ← מלאי. אחרי עדכון הקוד יש להריץ שוב את `supabase/gateway.sql`.

## טיפים

בלשונית היום יש כרטיס "טיפים": בסוף משמרת מוסיפים סכום ומסמנים מי עבד. החלוקה: עובדים רגילים חלק שווה, מתגבר/ת לפי שעות מתוך משמרת מלאה (8 שעות, בשבת 14), וכל הסכום מחולק עד האגורה. מנהלים רואים סיכום חודשי לכולם. אחרי עדכון הקוד יש להריץ שוב את `supabase/gateway.sql`, ולפרוס מחדש את הפונקציה `wix` כדי שמספרי שולחנות יופיעו.
